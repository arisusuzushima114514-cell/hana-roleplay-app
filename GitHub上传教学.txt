GitHub 上传教学（完全新手版）

这份教程是按你现在这个项目的实际情况写的。

你当前真正要上传的，不是原项目文件夹，而是我已经帮你整理好的这个副本：

C:\Users\Lenovo\Desktop\app\github

这个 github 文件夹已经比原项目更适合公开发布：
- 去掉了 build 缓存
- 去掉了 local.properties
- 去掉了 apk
- 去掉了本机专用路径
- 补了 README、LICENSE 等仓库文件

所以后面所有操作，都默认围绕这个文件夹进行。


====================
一、你要先明白的事情
====================

1. GitHub 不是“直接上传文件夹”就结束了。
2. 一般流程是：
   - 先在 GitHub 网站创建仓库
   - 再把本地 github 文件夹连接到这个仓库
   - 再上传
3. 你现在看到的“没有可选仓库”，就是因为你还没有先创建仓库。


====================
二、最推荐的方式
====================

最适合新手的是：

方式 A：GitHub Desktop

因为它可视化，出错概率最低。

如果你已经装了 GitHub Desktop，就优先用它。
如果没有，也可以用命令行，后面我也写了。


====================
三、先在 GitHub 网站创建仓库
====================

1. 打开 GitHub 官网：
   https://github.com/

2. 登录你的账号。

3. 点击右上角加号“+”。

4. 选择：
   New repository

5. Repository name（仓库名）建议你填：
   Hana

   也可以填：
   hana-app
   hana-roleplay-app

   最推荐：
   Hana

6. Description（描述）可以先简单写：
   An Android AI roleplay app with character cards, group chat, memory, and image generation.

   或者中文：
   一个支持角色卡导入、多角色群聊、长期记忆与生图的 Android AI 角色对话应用。

7. Public 还是 Private：
   - 如果你想公开给别人看，选 Public
   - 如果你只是先自己试，选 Private

   你现在如果是想发作品，我建议先选 Public。

8. 非常重要：
   创建仓库时，不要勾这些：
   - Add a README file
   - Add .gitignore
   - Choose a license

   因为我已经在本地 github 文件夹里帮你准备好了这些文件。
   如果网页上再勾，后面第一次上传时容易多一步冲突处理。

9. 点击：
   Create repository

创建完成以后，这个仓库就有了。


====================
四、用 GitHub Desktop 上传（最推荐）
====================

如果你已经安装 GitHub Desktop，按这个流程走。

步骤 1：打开 GitHub Desktop

步骤 2：登录你的 GitHub 账号

步骤 3：选择：
File -> Add local repository...

步骤 4：选择本地文件夹：

C:\Users\Lenovo\Desktop\app\github

步骤 5：如果它提示这不是一个 Git 仓库：
选择：
Create a repository here

步骤 6：填写信息：
- Name：Hana
- Description：可以简单写一句
- Local path：确认是 github 这个文件夹

步骤 7：创建后，它会看到所有文件。

步骤 8：在左下角 Summary 填提交说明，建议写：
Initial commit

步骤 9：点：
Commit to main

步骤 10：提交完以后，右上角通常会出现：
Publish repository

步骤 11：点击 Publish repository

步骤 12：确认：
- Name 是你要的仓库名
- Keep this code private：如果你要公开，就不要勾

步骤 13：点击 Publish Repository

完成。


====================
五、如果 GitHub Desktop 里提示没有仓库可选
====================

这通常不是错，只是你在“选择已有仓库”的界面里。

你要找的不是“Select an item”，而是下面这些按钮之一：
- Add local repository
- Create a repository here
- Publish repository

如果你已经先在 GitHub 网站创建了仓库，但这里仍然显示没有可选项，也不用慌。
你仍然可以：
1. 先把本地 github 文件夹做成仓库
2. 先 commit
3. 再点 Publish repository

很多时候不需要先从“列表里选仓库”。


====================
六、命令行上传方式（备用）
====================

如果你不用 GitHub Desktop，也可以用命令行。

注意：下面这些命令，都是在这个文件夹里运行：

C:\Users\Lenovo\Desktop\app\github

步骤 1：打开终端，进入该目录。

步骤 2：执行：

git init

步骤 3：执行：

git add .

步骤 4：执行：

git commit -m "Initial commit"

步骤 5：把你的 GitHub 仓库地址填进下面这条命令：

git remote add origin https://github.com/你的用户名/你的仓库名.git

例如：

git remote add origin https://github.com/yourname/Hana.git

步骤 6：执行：

git branch -M main

步骤 7：执行：

git push -u origin main

如果 GitHub 要你登录，就按提示登录。

完成以后刷新 GitHub 网页，就能看到项目了。

====================
十一、如果你卡住了，最常见问题是这些
====================

问题 1：No repositories available
原因：你还没创建 GitHub 仓库，或者你在错误的界面。

问题 2：提示不是 Git 仓库
原因：本地文件夹还没 init。

问题 3：推送失败要登录
原因：GitHub 要求身份验证。

问题 4：上传后 README 不对
原因：可能网页创建仓库时勾选了自动 README，和本地冲突。

问题 5：别人拉下来构建失败
原因：每个人本地环境不同，所以 local.properties、JDK、SDK 都要自己配。
